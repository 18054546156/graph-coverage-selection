EVA METHOD SUMMARY
────────────────────────────────────────────────────────────────────────────────

Input:     Full training dataset with hard labels
Process:
  1. Divide training into 2 time windows
  2. Track sample importance evolution across windows
  3. Compute variance of importance per sample
  4. Select top-K samples by variance

Output:    Compressed dataset (~10% of original)
Result:    98.27% accuracy (vs 97.20% baseline with 100% data)

Strengths:
  ✓ Effective at extreme compression (5-10%)
  ✓ Medical imaging specialized
  ✓ Simple implementation
  ✓ No pre-training required

Weaknesses:
  ✗ No geometric diversity guarantee
  ✗ No theoretical bounds
  ✗ No soft label integration
  ✗ Requires full training
