给外行人的研究路线图 · 方案一

Cloud Agent 方案：先验证局部几何，再谈维度配额

这套方案的核心不是先宣布“医学图像是分形的”，而是先问一个更朴素的问题：如果两张图在 UNI 表示空间里很接近，它们是否真的可以互相代表？只有这个问题有证据，后面才值得研究“区域需要多少张图”。

先记住一条主线

流形思想不是一个按钮。 它被拆成三层：近邻是否可替代 → 几何选样是否有效 → 局部维度是否能决定区域预算。前一层失败，后一层就没有实际基础。

它到底在处理什么数据？

输入

一张医学图像

五个 MedMNIST 数据集中的训练图像，例如血细胞、器官、病理组织。每张图像都有一个类别标签。

表示

UNI embedding

UNI 模型把一张图像转换成一个 1024 维向量。向量不是图像本身，而是模型认为图像有什么特征的数字表达。

目标

固定预算选样

例如每个类别只能选 50 张。所有方法最终都选同样多的图，才是在比较“选谁”而不是比较“给谁更多资源”。

第一层：图像之间是否可以互相代表？

把 UNI 向量归一化为 zᵢ，用欧氏距离衡量两张图在表示空间里有多远。对每张未选图，找同类别中最近的已选代表。

zᵢ = φ(xᵢ) / ‖φ(xᵢ)‖   ；   πS(j) = 离图像 j 最近的已选同类代表

如果图像 j 和代表 πS(j) 很接近，就表示它们在 UNI 空间中相似。但这还只是几何证据，不等于分类器一定会给出同样预测。

D(S) = Σj pj d(j, πS(j))

这里 D(S) 是平均代表距离。为了对应 balanced accuracy，每个类别先平均，再在类别之间平均。越小越好。

第二层：固定每类预算，只比较选哪些图

每类 50 张，所有方法等权

五个数据集、每类最多 1,000 张候选图、每类固定选择 50 张。6 个独立 block 作为 pilot。Random 已经是类别均衡随机，不另造一个重复的“均衡 Random”。

四种选择方法

Random：每类随机抽 50 张。
Herding：挑选后尽量接近该类的平均向量。
Graph-A2：在 embedding 上建 k=10 的近邻图，使用 1 跳和 2 跳结构。
直接几何覆盖：用 facility location，让选中点尽量覆盖同类候选点。

先用冻结 UNI 线性头做便宜检查

先不训练昂贵的图像分类器，而是用选中的 UNI 向量训练一个简单线性分类器，在 train-only audit split 上测 BA、NLL、Brier、ECE 和每类 recall。若几何方法连这个便宜检查都没有稳定信号，就不应直接跳到“维度决定预算”。

第三层：任务几何有没有额外价值？

纯 UNI 距离可能主要保留颜色、染色、背景或来源。Cloud Agent 因此提出一个小 pilot：每类先共享 10 张图，在这 10 张图上训练一个线性分类头。

gᵢ = vec[(pᵢ − eyᵢ)(zᵢ,1)T]

混合距离同时考虑“图像像不像”和“对任务的训练作用像不像”：dτ² = (1−τ)dUNI² + τdgradient²。Cloud Agent 建议用四个臂比较：Random + pilot、纯几何 + pilot、任务几何 + pilot、类内打乱梯度对应的控制组。

最关键的对照：任务几何不能只和纯几何比较，因为任务几何额外使用了标签和 pilot 训练头。真正干净的机制比较是“正确对应的任务梯度”对“类内打乱后的任务梯度”。

为什么还要研究维度？

前两层只问“在每个区域固定拿多少张时，选谁”。第三层才问“不同区域要不要拿不同数量”。如果一个区域用 n 张代表的失真近似为：

Dr(n) ≈ ar n−γr

在总预算固定时，拉格朗日条件给出：

nr = [prLrarγr / λ]1/(γr+1)

只有在额外规则性条件下，才可能近似 γᵣ ≈ 1/dᵣ。所以“高维区域一定多给图”不是理论结论，必须通过实验验证。

第三轮必须有直接失真对照

Cloud Agent 的方案已经包含这个重要思想：不要只比较“质量、维度、随机”，还要直接测量一个区域多给一张代表能减少多少失真。

Δr(k) = Dr(k−1) − Dr(k)

然后把下一张图给当前边际收益最大的区域。这个方法可能比维度拟合更便宜、更准确；如果是这样，维度就没有额外价值。

Cloud Agent 方案的结论规则

结果应该怎样解释
近邻不可替代UNI 几何没有保留足够的分类相关信息，停止流形选样主线。
几何覆盖优于 Random，但任务几何不再增益UNI 空间有用，但 pilot 梯度没有带来可验证的额外信息。
任务几何优于打乱控制分类相关的局部几何有机制证据，但仍需真实分类器训练确认。
维度分配优于直接边际失真只有在成本相当且 source-validation 上稳定优于直接曲线时，才支持维度的额外价值。
这份页面解释的是 Cloud Agent 提出的“先固定预算、后研究维度配额”的方案。它的重点是研究顺序和可证伪性，而不是预先假定流形理论一定正确。
