一、为什么要重新分析？

之前看到过一种表面现象：herding 的覆盖距离更小，BA 也更高，于是很容易得出“覆盖距离导致 BA 提升”。但这里有一个混淆：herding 可能在许多方面同时更好，覆盖距离只是跟着它一起变化。

二、当前已有结果说明了什么？

任务梯度没有通过

五个数据集的 task geometry 相对类内置换对照平均只有 +0.191pp，没有达到预设的 +1pp 门槛。这里失败的是“这个任务梯度对应关系带来足够增量”，不是所有 UNI 几何。

数据集难度差异很大

pathmnist 的 50 张/类 probe headroom 只有 0.61pp，organsmnist 是 13.22pp。统一要求每个数据集都提升 1pp 并不公平，后续要同时报告绝对增益和相对 headroom 增益。

预算 25 是训练工作点

预算阶梯只比较 random 和 herding，并用它来选择真实训练 operating point。它不是五个数据集上新方法已经胜出的证据。

当前回溯检验的核心数字：在同一数据集、同一 cap、同一预算、同一方法臂内部，用 covering distortion 预测 probe BA 时，记录的相关约为 r = +0.014，t = 0.21；把不同审计集的难度改成 gap 后仍接近零。此前看到的 107/120 同号主要可能是 herding 整体更好造成的共同变化，而不是覆盖距离本身造成 BA 提升。这个结论仍应由修复后的完整泛函筛选独立复现。
固定预算内的关键假设：覆盖距离在不同预算之间会和 BA 一起变化，但这可能只是“预算越多，两者都改善”。要判断覆盖是否真的有用，必须在同一个数据集、同一个预算、同一个方法族内制造连续变化。

因此新筛选器会从一个选择集合中替换同类图像：替换 1、2、5、10、25 张。这样预算不变，类别配额不变，只改变选择集合的特征。当前 HPC 上的 functional_screen.py 正是为这个问题设计的，但完整作业 33707 还没有产出数据。

不能从目前结果推出“流形方法整体失败”“高维区域不重要”或“herding 永远最好”。也不能把线性 probe 的 BA 直接当成 ResNet 的训练表现。真正的选择器结论必须来自固定预算、独立重复和真实训练。

三、新实验具体在测什么？

新实验不是只试一个新名字，而是先把“一个选中的集合”从多个角度描述。所有候选方法都保持每类预算 25 张，避免预算大小成为混淆因素。

特征家族代表量小白解释可能告诉我们什么
覆盖失真dist_mean、dist_p90、dist_max未选图离最近代表有多远，平均、90% 分位和最坏情况分别是多少。集合是否能覆盖大多数样本，还是留下长尾空洞。
分布保持moment1、moment2、mmd2选中图的中心、离散程度和整体分布是否像候选池。是否保留了类别内部的主要模式，而不是只挑边界或只挑中心。
代表集中度mass_gini、centrality、spread、logdet少数代表是否承担了太多样本，以及所选点是否过于挤在一起。是否存在“看起来覆盖好，实际权重极端集中”的集合。
难例和边界purity、margin、sel_margin_min、xclass_sep选中的图是容易样本、类别边界样本，还是可能混淆的样本。医学图像任务中，模型真正需要的可能是可区分类别的边界，而不只是空间覆盖。
局部密度density一张图周围有多少相似图。区分稀有模式和大量重复模式，避免把离群点误当成有价值多样性。

四、我建议的新方法：RAMP-Select

建议把下一代方法命名为 RAMP-Select：Risk-Aware Margin-and-Prototype Selection，中文可称“风险感知的边界—原型联合选样”。它不是把“高维”直接转换成“多选”，而是同时保护三类东西：

原型

代表主要模式

用 k-medoids 或 facility coverage 保留类别内部的主要形态，降低重复。

边界

保留难区分样本

优先加入低 margin、高不确定性但不是明显错误的样本，防止只选中心图。

稀有模式

保护小区域

按局部密度、类别内部簇大小和 source-validation 需求设置最低保护量，避免大簇吞掉小簇。

Score(i | S) = λproto·prototype_gain(i|S) + λboundary·boundary_value(i) + λrare·rare_mode_value(i) − λredundancy·similarity(i,S)

每个类别内部做贪心选择，直到达到固定预算。这里的权重 λ 不能看 test 调；先在 calibration split 上用交叉拟合选择，再锁定到 source-validation。若泛函筛选发现某一项无效，就把对应系数设为 0，而不是强行保留“流形”术语。

为什么它可能超过单一覆盖方法？

单纯 herding 倾向于保持整体均值；k-center 倾向于照顾最远点；facility coverage 倾向于减少平均距离；hard-example 选择又可能只挑噪声或异常。RAMP-Select 的目标是把它们的互补部分放在同一个固定预算目标中，同时用密度和边界可信度抑制两个风险：

要保留的东西
主要模式、类别边界、稀有但可重复的子区域、训练时的代表质量。
要防止的东西
近重复堆积、孤立噪声、全选中心样本、把类别数量先验误当成几何收益。

六、怎样避免新方法又变成“调到显著”？

  1. 先固定候选特征集合和数据拆分：selection pool 用来选，calibration 用来拟合权重，source-validation 用来比较，official test 最后只用一次。
  2. 不要按 test BA 选择竞争区。可以预先定义“结构上相近的方法族和小扰动”，结果定义的“离最优 2pp 内”只能作为描述性分析。
  3. 把五个数据集作为主要重复单位，同时报告单数据集结果；不能把所有图像或所有 block 当成独立生物学重复。
  4. 设置 oracle upper bound：先问“预算分配理论上有多少空间”，再问 RAMP-Select 能否接近这个上限。
  5. 如果 RAMP-Select 不能超过最强基线，就保留负结果。真正的创新可以是证明“哪些几何量在医学图像选样中没有增量”，而不是事后改门槛。

七、目前最诚实的结论

当前证据支持：UNI 表示空间包含有用信息；不同数据集的 headroom、密度和局部结构明显不同；单一覆盖距离不足以承担“预测下游精度”的任务；下一步应从“覆盖优先”转向“原型 + 边界 + 稀有模式”的受控特征筛选。
当前还没有证明：RAMP-Select 已经超过所有方法；15 个泛函中谁最好；真实 ResNet 的加权 interaction 最终是否成立。因为新筛选作业目前没有输出，真实训练也仍在运行。
