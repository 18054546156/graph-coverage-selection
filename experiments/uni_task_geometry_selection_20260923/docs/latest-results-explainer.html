给小白看的结果说明

这次到底算了什么？

这轮不是只算一个“分数”。我们从五个角度检查：UNI 是否保留了分类信息、五个数据集的样本结构是否一样、选中的图覆盖得好不好、加权到底改变了什么，以及便宜的线性 probe 能不能代表真实训练。

先给结论：这次结果没有证明“流形方法失败”，但证明了几个更具体的事实：pathmnist 对 UNI 已经非常容易；bloodmnist 有很多近邻和较大的代表权重不均；organsmnist 的加权收益一部分来自类别数量不平衡；任务梯度几何目前没有通过主门槛；真正需要用 ResNet 训练确认的是“覆盖加权是否改善真实模型”。

一、整个计算流程像什么？

简单说：先看“UNI 空间长什么样”，再看“选择器怎么选”，最后才问“训练出来的模型有没有变好”。

1. Probe BA：UNI 本身能分对多少？

BA 是 balanced accuracy，取各类别 recall 的平均值。 例如 pathmnist 的全量 probe BA 是 0.9928，表示仅靠 UNI 向量训练的简单线性头，五个类别平均已经能达到约 99.28% 的分类水平。

2. 余量 headroom：还有多少提升空间？

余量不是“现在的错误率”，而是“预算 50 张的结果距离全量训练上限还有多少 BA”。pathmnist 只有 0.61 个百分点余量，所以任何方法最多也只能在这条线附近提升。用绝对值 +1 个百分点作为所有数据集统一门槛，会让 pathmnist 在原则上无法通过。

headroom = BAfull pool − BAbudget 50

3. 最近邻中位距离：图像在 UNI 空间里挤不挤？

每张图找离它最近的另一张图，再取所有最近邻距离的中位数。数值小表示点挤在一起，大表示点更分散。pathmnist 是 0.652，全场最大，说明它在 UNI 空间里并不近重复；bloodmnist 是 0.290，点更拥挤。

4. 本征维数：局部几何需要多少个方向？

它不是图像的像素维度，也不是“越高越好”。它是对局部邻居距离变化的概括：organ 家族约 8–9，blood/tissue 约 24，path 约 17。当前只是描述性先验，不能据此宣布高维区域一定多选。

三、第二组：重复、类别数量和代表权重

near_duplicate_rate：有多少图像离另一张很近？

这里用阈值 d < 0.25。bloodmnist 是 19.10%，organamnist 是 1.87%，organsmnist 是 0.33%，pathmnist 是 0%，tissuemnist 是 0.07%。

原本猜 pathmnist 因为同一切片的 tile 会有很多近重复，但实际没有。说明像素层面的相关性没有自动变成 UNI 表示空间里的近重复。

pool imbalance ratio：最大类有多少倍样本？

如果一个数据集某些类候选图更多，全局权重重标可能把“样本多”误当成“分类目标更重要”。organsmnist 的比值是 1.63，是五个数据集中唯一明显不平衡的一个。

而最终 organsmnist 的加权增益最大，所以必须把覆盖效果和类别先验效果拆开。

Voronoi mass Gini：代表权重是否集中？

每个选中代表负责一批未选图。负责得越多，它的 Voronoi mass 越大。Gini 越高，表示少数代表吸收了更多样本权重。bloodmnist 是 0.4632，全场最高。

这可以提示“一个代表点是否承接了过多样本”，但不能只凭 Gini 就断言训练一定变差。

四、第三组：加权到底改善了什么？

把每个未选样本分配给最近的同类代表。若代表 i 负责的原始样本总质量是 wᵢ，就用 wᵢ 作为训练时的 sample weight。之后把同一个选样集用“等权”和“Voronoi 权重”各训练一次。

wᵢ = Σj:π(j)=i pj

对每个方法，真正看的变化是：

加权增益 = BAVoronoi weight − BAequal weight

五、把一个总效应拆成两个来源

加权变化可能来自两个完全不同的原因：

  • within：同一类别内部，覆盖失真被修复了。
  • prior：不同类别的总样本量不同，全局归一化改变了类别先验比例。
total = within + prior

因此之前“blood 的加权伤害来自近重复”的猜测被数据推翻了：近重复率高是真的，但实际伤害主要来自类别先验变化。

六、任务几何和置换对照算了什么？

任务几何先用公共 pilot 训练线性分类头，再为每张图计算“它对分类头的梯度向量”。这个向量描述：这张图会怎样推动分类头改变。

主比较结果平均只有 +0.191 个百分点，五个数据集没有一个达到预设的 +1pp 放行门槛，所以任务几何这条线是 NO-GO。这不是 UNI 失败，只是没有证明“pilot 梯度对应关系”带来足够增量。

为什么不能只比较 task geometry 和 pure geometry？ pure geometry 不使用标签，而 task geometry 使用标签；两者的信息量不同。正确对应 vs 类内打乱才是更干净的主比较。

七、预算阶梯：为什么后来选择每类 25 张？

先在多个预算下测加权与等权的交互效应。预算越大，等权选择本身已经覆盖得越好，重加权的额外空间通常越小。

数据集每类预算交互效应（百分点）标准误如何读

选择 budget=25 不是因为看到了最大点估计就挑它，而是因为它是误差棒后唯一在三个独立来源上都稳定的工作点。organamnist 与 organsmnist 来自同一批 CT 来源，不能简单算两个完全独立的数据来源。

八、真实 ResNet 训练与 360 个 cell

冻结 UNI probe 只能做便宜筛查，不能代替真实模型训练。当前冻结的真实训练设计是：

3 个数据集

blood / organs / tissue

pathmnist 余量只有 0.61pp，在绝对 +1pp 门槛下结构性不可能通过；organamnist 和 organsmnist 合并考虑来源独立性。

2 个选择臂

Random / Herding

重点测试覆盖权重是否对不同选样结构产生不同作用。

3 个权重

equal / voronoi_within / permuted_within

permuted_within 是负对照，检验权重是否因为真实空间对应关系才有效。

组合为：

3 数据集 × 2 选样臂 × 3 权重臂 × 10 复制 × 2 training seeds = 360 个 cell

主估计量不是单看“加权比等权高多少”，而是差中之差：

DiD = [Randomweighted − Randomequal] − [Herdingweighted − Herdingequal]

这样可以抵消“加权本身改变了有效学习率或正则强度”的共同影响，只看加权和选样方法之间的交互。

九、已有真实训练冒烟结果应该怎样理解？

organ­s­mnist 的一个完整复制在每类 25 张时 BA 为 0.59–0.64，而随机水平约为 1/11=0.09，说明 ResNet 确实学得动。

但这只是 n=1 的冒烟复制。这个复制的 DiD 是 −0.14pp，与 +2.92pp 和 0 都相容，不能用来推翻或证明整个 360-cell 实验。

诚实的读法：它证明“训练管线能工作”，不证明“加权有效”或“加权无效”。最终判断要等完整配对重复。

十、从哪些角度在算？

角度代表指标它回答的问题不能回答什么
表示角度Probe BA、full-pool BA、headroomUNI 是否保留分类信息？还有多少提升空间？不能证明选样训练一定更好。
空间结构角度NN 距离、近重复率、本征维数点是拥挤还是分散？局部复杂度如何？不能直接决定应该多选还是少选。
覆盖角度Voronoi mass、Gini、D(S)选中代表覆盖了多少样本？权重是否集中？覆盖最低不等于 BA 一定最高。
类别先验角度pool imbalance、prior 分解效果是否来自类数量比例改变？不能把 prior 效应叫作几何修补。
训练角度equal vs weighted、DiD、BA几何权重是否真的影响模型学习？probe 的小增益不能自动外推到 ResNet。
统计角度SE、block 同号、独立来源数结果是否稳定，是否可能只是噪声？单个数据集或单个复制不能定论。

十一、现在最合理的结论

可以保留的方向
UNI embedding 的局部结构值得研究；覆盖失真、代表权重和真实训练之间存在可检验关系；预算越小，权重修补空间可能越大。
现在不能说的事情
不能说高维区域一定更重要；不能说近重复必然导致加权伤害；不能把 probe 的 +0.85pp 直接当成真实 ResNet 结论。
当前实验状态：线性 probe 和结构诊断已经完成；真实训练 runner 已通过冒烟检查，完整 360-cell 实验正在按冻结协议执行。最终论文级结论必须等待真实训练的配对结果。
