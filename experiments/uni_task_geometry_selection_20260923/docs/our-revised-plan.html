给外行人的研究路线图 · 方案二

我的加强版方案：先把工程和因果对照做干净

我接受 Cloud Agent 的大方向，但我会再加一层“实验卫生”：先防止内存爆炸和标签错位，再把任务几何、训练权重、直接失真、维度分配和 oracle 上界分开。这样最后得到的结论才知道是在说方法，还是在说代码错误。

一句话区别： Cloud Agent 给出了正确的研究顺序；我的版本把每一层变成可以审计的质量门，并加入一个更强的直接基线、一个上界 oracle，以及理论与等权训练之间的桥接实验。

两套方案共同相信什么？

先测试局部代表性和任务几何，再把局部维度作为第三轮的增量假设。

我的完整流程

第 0 阶段：先证明数据没有错

0
标签对齐检查

UNI embedding 文件可能只有 embeddings，标签来自另一个 npz。仅检查长度不够，因为顺序错位仍然会通过。加强版会用固定抽样、类质心分类和 hash/索引记录做 sanity check；明显低于随机水平就停止。

✓
split 边界

训练候选池内部再分 selection 与 train-only audit。正式效果必须使用 source-validation；官方 test 不参与调参、选阈值或决定是否继续。

第 1 阶段：修好“能不能跑”的工程问题

原来的 facility location 写法会先生成 (800, 800, 1024) 的差分张量，约 2.6 GB，还要和 tissue 的全量 embedding 同时存在 4 GB 内存里。加强版改用矩阵恒等式：

‖a−b‖² = ‖a‖² + ‖b‖² − 2a·b

这样主要距离矩阵只有 (800,800)，约几 MB。Graph-A2 也要保持稀疏 CPU 路径。工程上不先修复内存，就不能把失败解释成医学图像几何无效。

第 2 阶段：固定预算的两轮实验

Round 1：每类 50 张

比较 Random、Herding、Graph-A2(k=10, hops=2)、直接 UNI facility coverage。6 个 block 先做 pilot。先用冻结 UNI 线性头快速筛查，再进入真实分类器训练。

Round 2：共享公共 pilot

每类 10 张公共 pilot，最终仍是每类 50 张。比较 Random + pilot、几何 + pilot、任务几何 + pilot、打乱任务特征 + pilot。主对照是任务几何 vs 类内置换控制，因为两者都使用标签和任务特征，只有正确对应关系不同。

dτ² = (1−τ)‖Δz‖² / sz² + τ‖Δg‖² / sg²

若代码令 UNI 已归一化并固定 sz = 1，协议必须明确写出来；梯度尺度用随机配对而不是按样本原顺序的相邻配对估计。

真实训练不是装饰

冻结 UNI 线性头只能证明表示空间里有信号，不能证明选出的图像能改善最终模型。真实分类器阶段必须固定初始化、训练轮数、优化器、数据增强、loader seed，并使用 source-validation 评估。

第 3 阶段：把理论和训练权重接起来

局部覆盖理论常见的风险界需要代表点承接其所代表样本的质量权重：

wᵢ = Σj:πS(j)=i pj  ；  |RD(θ) − RS,w(θ)| ≤ L D(S)

如果所有训练样本仍然等权，那么这个界只是动机，不是被实验直接检验的对象。因此加强版加入一个低成本加权臂：等权结果仍保留，另外报告按最近代表分配的 sample_weight 结果。这样可以回答“覆盖好”与“覆盖加权训练好”是不是同一件事。

第 4 阶段：三个分配器加一个 oracle

分配器怎样做它回答什么
Mass fallback按区域样本量和预注册 floor 分配不使用复杂几何时的基线
Dimension law拟合有限尺度 covering slope，再用目标函数推 quota维度是否能成为区域预算信号
Direct marginal直接估计 Δr(k)=Dr(k−1)−Dr(k)真实失真曲线是否比维度更准
Calibration oracle在 calibration/audit 上直接选择最优配额整个分配问题理论上还有多少可提升空间

Direct marginal 必须和 dimension 使用同一套区域、同一总预算、同一 selection/source-validation 分割。若 direct 已经达到 oracle，dimension 不应再被包装成必要组件。

最重要的统计规则

6 个 block 是 pilot

它们用于估计配对差的方差，不是自动证明样本量够。相同 seed 重跑只能检查可复现性；不同 seed 的 paired difference 才决定正式重复数。

主比较必须预注册

Round 2 的主比较是 task geometry − permuted control；Round 3 的主比较是 direct marginal − dimension。不能看到结果后换成最有利的差值。

tau 不能事后调

τ=0.5 先冻结；若要比较 τ=0.25/0.75，必须是预注册敏感性分析，不能根据 audit 结果挑最显著的一个。

外行版决策树

如果 task geometry > permuted control说明“正确的任务信息对应关系”可能有价值，进入真实分类器训练。
如果二者没有差异不要把任务梯度包装成成功；保留纯 UNI 几何或停止任务几何路线。
如果 direct marginal > dimension优先采用直接失真分配；维度只能作为压缩近似或解释变量。
如果 dimension > direct必须检查成本、泄漏、曲线拟合窗口和 oracle 余量，不能只看一个平均 BA。
