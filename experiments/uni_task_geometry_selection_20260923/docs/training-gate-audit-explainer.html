Voronoi 加权为什么关闭？

这次不是“探针结果不好看，所以关闭方法”。相反，探针上的信号非常稳定；真正的问题是：这个信号没有在同一批图像上转化为从头训练 ResNet 的精度提升。下面把代码怎样算、输出怎样算、已经证明什么，以及还没有证明什么分开讲清楚。

一句话结论：在当前协议下，UNI embedding 计算出的类内 Voronoi 代表权重没有改善真实 ResNet 的 balanced accuracy。预注册 gate 的输出是 REFUTED，所以“Voronoi weighting × random/herding”的分支应关闭；不能继续用 probe 的离线增益为它辩护。

一、实验到底比较了什么？

注意：几何是在 UNI embedding 中计算，真实模型是在原始 224px 图像上从头训练 ResNet18。正是这个“表示空间不同、最终模型不同”的落差，需要用真实训练来检验。

二、代码如何计算最终 gate？

文件 gate_training.py 明确规定：

DiD = [BA(random, Voronoi) − BA(random, equal)] − [BA(herding, Voronoi) − BA(herding, equal)]

通俗地说：

步骤含义
第一组差值Random 选出的同一批图，加 Voronoi 权重后比等权高多少。
第二组差值Herding 选出的同一批图，加 Voronoi 权重后比等权高多少。
两组相减扣除“加权本身改变训练行为”的共同影响，只看加权是否特别适合 random 而不适合 herding。
每个数据集10 个 selection replicate × 2 个 train seed = 20 个配对单位。
最终 pooled代码先算三个数据集各自的 mean，再对三个 mean 取平均，不是把所有图像混成一个独立样本。

三、探针结果为什么看起来很强？

预算阶梯在 full train pool、每类 25 张时，先用线性 probe 预测了 Voronoi weighting 的交互效应：

数据集Random 加权增益Herding 加权增益Probe DiDblock 方向
bloodmnist+1.034pp−0.016pp+1.05pp4/4 正
organsmnist+2.038pp−0.886pp+2.92pp4/4 正
tissuemnist+1.289pp−0.316pp+1.60pp4/4 正

“4/4 同号且超过 2SE”表示：在四个独立的 train-only block 中，probe 每次都给出同方向，而且相对 block 波动看起来足够大。这证明了 probe 的离线统计信号稳定，但还没有证明它能预测真实 ResNet。

六、这是不是说明探针完全没用？

不能这样说。HPC 上的 probe_vs_training.py 做了更关键的检查：固定数据集，比较同一批 10 个 random 选择和 10 个 herding 选择，探针 BA 是否能排出真实训练 BA 的相对顺序。

分组nSpearman解释
blood / random10−0.067探针排序与训练排序相反但接近零。
blood / herding10−0.261没有可靠排序能力。
organs / random10+0.321弱正相关，样本太少。
organs / herding10+0.176弱正相关，不能作为可靠筛选器。
tissue / random10+0.564看起来较强，但只有 10 个选择。
tissue / herding10−0.018没有排序能力。
六个方法内部格子的平均6+0.119不能把 probe 当作真实训练排序器。
为什么把两种方法合并会误导？因为 herding 在 probe 和真实训练上整体都不同于 random。把两臂合并，相关性主要反映“herding 与 random 的方法族差异”；真正需要的问题是：在同一个方法族内部，probe 更高的那个选择是否真的训练更好。当前数据对此没有足够证据。

七、这次真正证明了什么？

已经证明或强烈支持

1. Voronoi within weighting 的预注册 interaction 没有在真实 ResNet 上复现。

2. UNI probe 上很稳定的离线增益，不等于真实像素模型的精度增益。

3. 选样方法之间的整体差异，不能代替同一方法内部的排序验证。

4. 当前 Voronoi 加权分支应关闭，而不是继续调权重。
还没有证明

1. Herding 在所有医学图像数据集上永远最好。

2. UNI embedding 对选样完全没有价值。

3. 所有覆盖、边界或动态特征都无效。

4. 新的 RAMP 或动态选择方法一定能超过基线。

5. “真实训练噪声与选择信号同量级”的信度分解已经被当前 JSON 完整保存；当前可直接核实的是 6 个组内相关系数。

八、下一步应该怎样优化，而不是继续重复失败？

第一步

先修正测量尺度

完整运行无 cap 的五数据集先验，重新计算 pathmnist 的 headroom、全池最近邻和局部标签混合度。旧的“path headroom 0.61pp”来自 capped pool，不能继续作为排除依据。

第二步

把动态基线加入筛选

当前代码已经接入 forgetting、AUM、EL2N、CCS、Moderate 以及 11 个动态泛函。五个 dynamics cache 都存在，但完整 screen 还没有有效输出。

第三步

最终端点改用真实训练

probe 只能作为便宜的候选筛选器；最终方法选择必须用真实模型、固定训练协议、source-validation 和足够的 train seeds。不能再用 probe gate 直接放行 GPU 结论。

新方法候选评价顺序：全尺度先验 → 动态与几何特征筛选 → 同方法内部排序 → 真实训练 → 五数据集确认

只有当一个特征在同一数据集、同一预算、同一方法族内部仍能预测真实训练表现，并且跨独立 block 重复，它才有资格进入新的图像选择器。这样得到的创新方法可以是“动态难度 + 类内原型 + 稀有模式保护”的组合，但不能先写方法再用 probe 证明它。
