Graph-A2：为什么“覆盖邻域”比只看距离更适合选数据？

这页把论文第 2.1–2.3 节翻译成一个可以手算、可以点击运行的小实验：先把图像变成向量，再把向量变成图，最后在每个类别预算有限时，贪心地挑出最能覆盖全体数据的样本。

先给结论：Graph-A2 的可验证核心是“图上的两跳覆盖 + 受类别预算约束的 facility-location 贪心”。它能给出组合优化目标的理论保证，但不能自动保证 ResNet 的 balanced accuracy，也不能仅凭公式证明“二跳一定最好”。

核心思想面向外行

把“选代表图片”改写成“覆盖更多邻域”

普通的随机选择只问“抽到了哪些图片”；只看欧氏距离的方法只问“图片之间离得多远”。Graph-A2 额外问了一层：一张图片周围有多少相似图片？两个不直接相似的区域，是否通过共同邻居连接？因此一个样本的价值，不只是它自己像谁，而是它能代表多大的局部结构。

01图像 + 标签训练集中的图片，以及它属于哪个类别。
02UNI embedding冻结视觉模型，把每张图变成 1024 维向量。
03全局 k-NN 图每个样本连接最相似的 k 个邻居，允许跨类别连边。
04两跳覆盖核 KK = Asym + Asym2，合并直接和间接邻域。
05类别预算每个类别只能挑 B 个，防止大类把预算全占走。
06贪心挑选每次选择当前新增覆盖量最大的合法样本。

符号含义外行版理解

yi第 i 张图片的类别标签例如 PathMNIST 的类别编号。

ρ相关性系数，例如 Spearman 相关两个方法给每个样本打分的排序是否相近；不是准确率。
公式拆解

从 embedding 到选择：每一步怎么算？

1. 把图片变成可比较的向量

UNI 接收一张 224×224 图像，输出向量 xi。这一步没有挑样本，只是在建立一个“图片坐标系”。之后只比较向量，不再更新 UNI。

x̄i = xi / ||xi||2

||xi||2 是向量长度。除以它以后，每个向量都落在单位圆/单位球面上，长度差异不会冒充语义相似度。

2. cosine 相似度怎么计算？

cos(xi, xj) = (xi · xj) / (||xi||2 ||xj||2)

点积“·”就是对应位置相乘后相加。结果接近 1 表示方向相同，0 表示大致无关，-1 表示方向相反。

例：A = (1, 0)，B = (0.97, 0.243)，那么 cos(A,B) = 1×0.97 + 0×0.243 ≈ 0.97，说明两者很接近。

3. 为什么论文说 Euclidean k-NN 等价？

当两个向量都已经 L2-normalized 时：

||x̄i − x̄j||22 = 2 − 2 cos(xi, xj)

右边只是 cosine 的单调变换：cos 越大，距离越小。所以“按 cosine 找最近”和“按 Euclidean 找最近”会得到同样的排序。这个等价性依赖于先归一化。

4. 生成 k-NN 邻接矩阵 A

Aij = { similarity(i,j), 若 j ∈ kNN(i); 0, 否则 }

这里的 i 是“发出观察”的节点，j 是“被观察”的候选邻居。先按每一行找 k 个近邻，因此原始图可能是有向的：i 认为 j 近，不代表 j 也把 i 排进前 k。

论文的对称化： A ← max(A, AT)。逐元素取较大值；只要任一方向发现了这条边，最后就保留它。

5. 为什么要做对称归一化？

D = diag(A1),　Asym = D−1/2A D−1/2

1 是全 1 列向量，所以 A1 会把每一行求和；D 的第 i 个对角元素就是节点 i 的总连接权。D−1/2 在左边和右边各放一次，意味着一条 i→j 的边会被节点 i、j 的连接量共同校正。

直观上：一个连接特别多的“枢纽”不能仅凭边多就覆盖所有人；归一化让不同密度区域更可比。

6. 两跳覆盖核 K

K = Asym + Asym2
(Asym2)ij = Σl=1N (Asym)il(Asym)lj

l 是中间节点。第一项表示 i 和 j 直接相连；第二项把所有“i→l→j”的两步路径乘起来再相加。共享中间邻居越多、边越强，间接覆盖越高。

7. facility location 的贪心选择

选中集合 S 后，样本 i 被覆盖的程度取决于 S 里最能覆盖它的那个样本：

covi(S) = maxj∈S Kij

尝试把候选 j 加入时，只有比当前覆盖更高的部分才算新增收益：

Δ(j | S) = Σi=1N max(0, Kij − covi(S))

每轮做三件事：

  1. 对每个还没选的候选 j 计算 Δ(j | S)。
  2. 丢弃所属类别已经达到预算 B 的候选。
  3. 选择剩余候选中 Δ 最大的一个，加入 S，更新所有 covi。
“global” 的含义：图在所有类别混合后一次性构建。预算仍按类别限制，但边可以跨类别，因此靠近决策边界的样本可能同时覆盖两侧结构。

真伪核验
哪些结论是定理，哪些只是实验说法？
这是复现时最容易混淆的地方。论文中的算法公式、优化理论和下游准确率，属于三个不同层次。




可以严格成立：归一化后的距离等价
只要 xi、xj 都已 L2-normalized，平方 Euclidean 距离与 cosine 相似度满足上面的恒等式。因此 k-NN 的排序一致。这是代数事实。


条件下成立：facility location 的次模性
若 Kij 非负，目标 F(S) = Σi maxj∈S Kij 是单调次模函数；加入一个样本带来的收益会随着 S 变大而不增加。每类预算构成 partition matroid，标准简单 greedy 有 1/2 近似保证。
保证对象是 F(S) 这个组合优化目标，不是 balanced accuracy、训练损失或“选出的图像看起来更好”。


不能直接说成立：K 是 heat kernel
令 L = I − Asym，真正的热扩散核是：
exp(−tL) = exp(−t) Σm=0∞ (tm / m!) Asymm
论文的 K = Asym + Asym2 没有 identity 项，也没有 Poisson 衰减系数。因此更严谨的说法是受 heat diffusion 启发的稀疏二项式 surrogate，不是一般情况下精确等于 heat kernel。


必须用数据验证：二跳足够、相关性 ρ > 0.999
“A3 以后贡献很小”“二项式 K 与 full heat kernel 排序几乎一致”“ρ > 0.999”都依赖具体数据、k、hop、归一化和实现。它们是 ablation 或相关性实验结论，不能从公式本身推出。


当前复现不能声称：五数据集完整 Table 1 已确认
当前隔离目录已有 Graph-A2 三种子以及 v11 的 validation/test 结果，但完整八方法、五个数据集、两个比例、五个训练种子的全部下游结果尚未全部完成。没有跑完的单元必须标为 TODO。


评估风险：用 test 选 best checkpoint 会泄漏
如果每 10 个 epoch 都查看 test balanced accuracy，并从中挑 test 上最好的 epoch，那么 test 已参与模型选择。严谨协议应在 validation 选择 checkpoint，最后只在 test 上报告一次；代码若显式使用 test，应在报告中说明。

下游训练

统计口径
