### 0.1 命名：TDGS 里的 "TD" 不是 test / target（09-28 18:40 用户提问后补记）

- **TDGS = Task-Demand Graph Selection**。"Task-Demand" 指 Round 1 设计里的**训练池内 5 折 out-of-fold 代理概率**给出的"需求"：难度 d_i = 1 − p_i(y_i)、混淆方向 u_i（见 `code/tdgs_select.py` 文件头）。**任何 TDGS 臂都不读 test 图像、test embedding 或 test 标签**，只用 train pool + train labels（source-only，合法进作者 Table 1）。
- 用无标签 **test/target** embedding 的是更早的 **TD-Cover（Target-Demand）**（记忆 `td-cover-*`）：它是 transductive 的、只在 path 上有效（shift repair），不在 Table 1 协议内，**不属于本论文方法**。
- 实证后果：需求项本身**被证伪**（难度需求 −2.51pp，方向需求被置换控制打平）。存活的 `tdgs_cls` = **类作用域覆盖（class-scoped credit）+ 类等权**，里面已经没有"demand"。所以 **"TDGS" 这个名字已不描述方法**。
- 决定：**论文里改名**（候选：CSC = Class-Scoped Coverage 指 `tdgs_cls`；R1 方法若过门叫 ERC = Encoder-Robust Coverage）。**代码、文件、臂名保留 `tdgs_*`**，否则 260 个已训 cell 的路径和哈希无法追溯。定名待 R3 结果（若 R1 STOP，论文方法部分缩回"审计 + 负结果"）。

### 2.3 TDGS 公式与各臂

```
a_ij = 1[y_i=y_j] · K̄_ij (· d_i · ⟨u_i,u_j⟩ 在被证伪的臂里)     K = A_sym + A_sym²，k=50，global
F_task(S) = (1/C) Σ_c (1/|P_c|) Σ_{i∈P_c} w_i · max_{j∈S_c} a_ij
F_new = (1−λ)·F_G/F_G(P) + λ·F_task/F_task(P)，λ=0.5，每类配额 bpc = int(N·ratio)//C
```

## 3. 原理解释（按最终结果）

1. **为什么 `tdgs_cls` 在 2% 有效**：graph_a2 的目标 `Σ_i max_j K_ij` 与 BA 有两处失配。
   - (a) 跨类覆盖信用：预算会漏到决策边界的另一侧。漏多少可以事前量出来，就是跨类边占比（path 2.49% → tissue 66.06%）。
   - (b) 频率加权需求：大类的发言权按样本量放大，但 BA 给每类等权。
   - `tdgs_cls` 只修这两处，不改任何打分准则。
2. **G1**：作者的 per-class scope 在每个类内部**重建** kNN，于是边界点也能拿满 50 个同类邻居，边界信息被抹掉。我们在**全局** kNN 上 mask，并用 λ=0.5 保留全局项。两者是不同算子（J=0.09–0.62），实测差 +1.66pp（worst +4.15）。**不在作者已占的消融格里。**
3. **G2 要分开读**：
   - tissue 上把类内 K̄ 置换掉，损失 7.57pp，说明几何内容是真的。
   - 另外 4 个数据集上，`cls_perm` 和 `cls` 打平（−0.10），甚至比 graph_a2 高 +0.91。这正是 Act 2 平坦性的预测：跨类泄漏少的地方，只要把信用限制在类内，类内选哪些点就不再重要。
   - 两种读法合起来，还是那一句话：**准则不重要，信用的作用域和测度才重要**。几何只在跨类泄漏严重的地方起作用。
4. **G3**：单独改权重有害（tissue −6.11），因为跨类信用还在流动时，放大小类的需求会把预算推向跨边界"覆盖"小类的点。mask 之后，类等权才变成中性或有益。交互项均值为正（+1.12），但 blood 是反例（−5.46），所以论文写“mask 是主要可解释干预，权重是混合目标中的相对缩放”，**不写**“两个修正都需要”或“强交互”。
5. **λ=1**：命题 3 说明 λ=1 时类权重是惰性的，所以 `tdgs_lam1` 等于"全局 kNN 去掉跨类边后，逐类做 facility location"。结果：BA −0.52（在噪声内）、worst +0.57，path 上 −3.30。
   - path 的跨类边只有 2.49%，mask 几乎不起作用，丢掉全局项的代价在这里最直接。
   - 所以推荐 λ=0.5；λ=1 的 `(1−1/e)` 只作为理论注脚和消融端点。
6. **为什么 5% 失效（事后解释，要标明）**：从 2% 到 5%，每类配额 bpc 变成 2.5 倍，graph_a2 自己也能覆盖到类内的主要模式，跨类泄漏的边际代价下降，于是"深落平坦区"。只有 tissue 的跨类边高达 66%，泄漏到 5% 仍然是主要损失，所以 +4.13 保留下来。
   这和 Act 2 一致，也和"graph_a2 vs Random：2% +1.12pp，5% 无差异"（记忆 `table1-random-baseline-competitive`）同一个模式：**2% 是这个 benchmark 唯一有分辨力的预算。**
7. **已证伪、终局**：
   - `d_i`：−2.51pp。probe 在 path 上 OOF 99.7%，和最终学习器结构性错配。
   - 方向项：相对置换对照 −0.20pp。
   - 论文**不写**"类对特异需求"。
