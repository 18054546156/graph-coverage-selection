# 第一部分：原理 —— 这个方法到底改了什么

## 1.1 把 facility location 拆成三个可分离的部件

Graph-A2 最大化 `F_G(S) = Σ_{i∈P} max_{j∈S} K_ij`。这个泛函通常被当作一个整体，但它实际上是三样东西的复合：

```
F(S) = ∫_D  max_{j∈S} R(i, j)  dμ(i)
```

| 部件 | 含义 | Graph-A2 的选择 |
|---|---|---|
| **D** 需求集合 | 谁有资格提出"我需要被代表" | `D = P`（整个池子） |
| **μ** 需求测度 | 每个需求点的权重 | `μ_i = 1`（计数测度）⇒ `μ(类c) ∝ n_c` |
| **R** 代表关系 | `j` 能否代表 `i`，代表多少 | `R = K`，**与标签无关** |

选样文献几乎全部的工作都在改 **R 的几何**（kernel、hops、k、对候选点的难度重加权）或改 greedy 本身。本项目 20 条关闭线索也全在这里。Act 2 的结论是：**R 的几何已经饱和** —— 好子集区域占池子 20%，BA 在其上平坦，四种准则的跨度（1.48pp）小于四次随机抽样的期望跨度（1.78pp）。

我们改的是另外两个部件：

```
μ_i  = 1/(C · n_c)                      ⇒  μ(类c) = 1/C，与 BA 的类等权对齐
supp(R) ⊂ {(i,j) : y_i = y_j}           ⇒  代表关系必须同类
```

**这是本方法唯一的技术内容。** 不改准则、不改 kernel、不改 greedy、不改配额。说清这一点本身就是贡献，因为它把"为什么 20 条准则线索全归零"和"为什么这一条不归零"放进了同一个框架。

## 1.2 命题 1（测度错配）—— 以及为什么它单独不够

`BA(S) = (1/C) Σ_c recall_c(S)`，是**类等权**泛函。设每类召回是该类被代表程度的单调函数 `recall_c ≈ g_c(cov_c)`，`cov_c(S) = (1/n_c) Σ_{i∈P_c} max_{j∈S} R_ij`。则

```
∂BA /∂cov_c  = g'_c(cov_c) / C        ← 每类等权
∂F_G/∂cov_c  = n_c                    ← 每类按池子频率加权
```

所以 `F_G` 的 KKT 点一般不是 `BA` 的 KKT 点，除非所有 `n_c` 相等。

**必须诚实处理的自我反驳。** 本项目已经量过：per-class 斜率 `g'_c` **不相等**（11× 跨度，KKT 故事本身已被否），而且 `1/C` 因子把**任何配额重分配**压到噪声以下（held-out best-of-12 = −0.93pp，oracle 上限只有 +0.18/+0.68pp）。所以命题 1 **不足以**解释 +1.76pp。

**关键区分（这是论文的一个真正洞察）**：配额重分配改的是「每类给几个名额」；测度 `μ` 改的是「在**同一个固定名额** `bpc` 下，选哪些点」。这是两件不同的事，天花板也不同 —— 在固定预算**且固定配额**下，样本选择已被量到能把单类召回移动 **5–24pp**。配额杠杆已关闭，不蕴含测度杠杆关闭。论文必须显式写出这个区分，否则审稿人会拿我们自己的配额负结果来反驳我们。

## 1.3 命题 2（支撑集错配）—— 当前最清楚的机制假说

作者代码的注释把跨类信用当作特性：*"boundary samples get credit for covering nearby other-class samples"*。我们说这是缺陷，机制是五步，**每一步都有已测数据**：

| 步 | 断言 | 已有证据 |
|---|---|---|
| 1 | `K` 标签盲 ⇒ 候选点因覆盖**异类**邻居而得分 | 作者源码 + 注释 |
| 2 | ⇒ 在 `y_j` 类的 `bpc` 个名额里，greedy 偏好「标签不一致」的点 | **已独立测到**：`graph_a2` 的 picks 标签一致性 .844/.612，池子 .901/.679 |
| 3 | ⇒ 该类**类内**覆盖比可达到的更差 | `J(graph_a2, tdgs_cls)` 随跨类边占比单调下降 |
| 4 | ⇒ 单类召回可能受损，且在跨类边越多处更严重 | round 1 支持；round-2 的 2%/n=5 BA 为 +1.57pp，但类级噪声仍大，不能写成普遍定律 |
| 5 | ⇒ 加 mask 在低预算下可能修复它 | 2%：`tdgs_cls − graph_a2` = +1.57pp；5% = +0.39pp 且仅 2/5 数据集同向 |

第 2 步是整条链的枢纽，而它是**在提出本方法之前、为别的问题测出来的**（memory `graph-a2-prefers-label-incoherent-points`）。这类事后才发现的独立确证比任何新实验都有分量，论文里要显著位置引用。

## 1.4 算法性质：复杂度与保证（作者没说清、我们可以说清的地方）

**复杂度。** `K = A_sym + A_sym²`，k=50 ⇒ nnz ≈ `n·k²` 量级（tissuemnist 实测 615M）。mask 后 nnz 乘以 `(1 − 跨类占比)` —— 在 tissue 上反而**便宜一半**。lazy greedy 摊销 `O(|S| · 平均列 nnz)`。round-2 的五臂**全部不需要 probe**，选择阶段无 GPU、确定性。

**次模性与保证。** 两项都是非负加权 max-coverage 之和 ⇒ 单调次模；非负系数的凸组合仍次模，所以 `F_new` 次模，lazy greedy 适用。

但要说准：**每类等额配额是一个 partition matroid 约束**，不是基数约束。所以覆盖文献常引的 `(1−1/e)` 保证**不适用**，简单 greedy 只有 `1/2`。

> **订正（2026-09-28）**：原稿此处写"作者的表述含混，我们可以精确化，是免费的小贡献"——**错**。作者论文 §2.3 已明确写出 per-class 配额 = partition matroid ⇒ greedy `1/2`。这一条**不能**算我们的贡献，已删。

**可复用的理论事实**：当 `λ=1` 且 mask 全开时，`F_task` **跨类可分解**，问题退化为 C 个独立的基数约束次模最大化，每个恢复 `(1−1/e)`。同时，`1/(C·n_c)` 在一个类别内是常数；在固定 `bpc` 且全部填满时，它只会把该类目标乘以正数，不改变该类的最终 greedy 选集。这个 identity 只适用于纯 masked 端点；默认 `λ=0.5` 仍有 global term，因此不能套用。

# 第四部分：图的设计（Fig 1–6）

## Fig 1 — 方法示意图（必须 3 秒看懂）

两个 panel，同一个局部邻域：

- **(a) `graph_a2`**：中心候选点，k 邻域里混有异类点；箭头显示 credit 流向异类邻居，标注 **"credit leaks across the boundary"**；需求点大小按 `μ_i = 1` 一律相同。
- **(b) `tdgs_cls`**：同一邻域，异类边划掉（虚线+×）；需求点大小按 `1/(C·n_c)` 缩放，让小类的点明显更大。

标题写 **"we change the measure, not the criterion"**。这张图的唯一任务是防止审稿人把本方法归入「又一个覆盖准则」。

## Fig 2 — 平坦性（Act 2，论文的科学骨架）

**注意一个陷阱**：929 个 random subsets 是从标签**逐位 replay** 出来的，`R²_max` 只有 0.48–0.72，**不能**用于平坦性检验。必须用真训练的点。

所以用这个设计：每个 `(dataset, ratio)` 一列，画
1. 8 个基线方法的 BA 作点（真训练，5 种子均值）；
2. 旁边画 `random` 方法 5 个种子的实测范围（这是同子集换种子的 σ_run）；
3. 一条参考线标「四次随机抽样的期望跨度 1.78pp」。

核心信息一眼可见：**方法间跨度（1.48pp）比随机抽样跨度（1.78pp）还小**。

**Inset：Jaccard 尺子**，横条从小到大 —— 随机下界 0.010/0.026 → 跨方法 0.049 → `graph_a2` 在 1e-3 嵌入扰动下与自身 0.18–0.88。三个数量级的对照说明「方法彼此几乎不重叠，却同分」。

## Fig 3 — 机制预测散点，**用类级分析把 N 从 5 提到 47**

数据集级只有 5 个点、有效 N 2–3，说服力受限。

**做法**：把自变量和因变量都下沉到**类**。对每个类 `c` 算
- `x = 类 c 的跨类边占比`（该类节点的 `K` 条目里指向异类的比例）—— 事前可算
- `y = Δrecall_c (tdgs_cls − graph_a2)` —— `harvest.json` 的 `recalls[]` 里已经有

得到 `9+11+11+8+8 = 47` 个点。这是完全合法的：两个量都定义在类级别。

### 已实测的仪器性质（`code/class_mechanism.py`，零 GPU，已跑）

| 量 | 值 |
|---|---|
| 类级 Δrecall | mean **+1.57pp**，sd 4.15pp，range [−6.69, +13.05]，29/47 为正 |
| 方差分解 | between-dataset **20.7%** / within-dataset **79.3%** |
| within-dataset 方差拆分 | 观测 13.39 = **真信号 4.91** + 种子噪声 8.48 |
| 折算 sd | 真实类间异质 **2.22pp** vs 种子噪声 **2.91pp** |
| 任何 `x` 的 R² 上限 | **0.37** |
| 单类越过自身 \|t\|=2 的 | **13/47** |
| 饱和点（两臂 recall≡1.000） | 1 个（pathmnist/1），已排除 —— 零 headroom 是构造性的、不是测到的零 |

**这修正我自己先前的说法。** 我说过类级分析「对机制论证是质变」—— 过强了。实测：**噪声 sd（2.91）大于真信号 sd（2.22）**，`R²` 上限只有 0.37。按数据集级斜率（(5.55−0.43)/(0.66−0.025) ≈ 8.1 pp/unit）外推，类级回归的预期 `|t| ≈ 2.6`。所以它是**有分量的支持证据，不是决定性证据**。

**但回归本身是合法的，而且这点很重要**：y 的噪声只抬高斜率的 se，**不使斜率有偏**；而 `x` 是从 `K` 精确数出来的，**没有 errors-in-variables 衰减**。所以 N=47 的 OLS 是干净的，只是功效有限。
