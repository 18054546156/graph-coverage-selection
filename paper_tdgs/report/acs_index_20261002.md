# ACS (Ambiguity-aware Class-conditional Selection) — file index (2026-10-02)

New since the 09-28 snapshot the rest of this package describes. ACS fixes three failure modes
of `tdgs_cls` found by the earlier rounds: F1 is `tdgs_cls` itself (class-conditional coverage,
the existing baseline); F2 is a per-class kNN-agreement quantile filter; F3 is a per-class budget
split between herding (first `k_h = floor(τ·bpc + 0.5)` picks) and `tdgs_cls` lazy-greedy
warm-start for the rest. The grid is `q ∈ {0, .25, .5} × τ ∈ {0, .5, 1}`; `(q=0,τ=0) ≡ cls` and
`(q=0,τ=1) ≡ bench herding` (identity-verified against the already-trained cells, not retrained).

## Status

- **E0** (selection-side identity + descriptive checks) — **done**. 10/10 identity checks pass;
  F2 erases 0 classes at any quantile; the F3 typicality gap only appears at small
  budget-per-class (bpc ≤ 13).
- **E1** (new active-learning baselines: TypiClust, ProbCover, MaxHerding) — **done**, staged for
  all 18 (dataset × ratio) rows, main version + `_nolab` appendix variant.
- **E2** (625-cell dev-seed GPU screen, seeds 42–46, to pick 1 of 12 candidate rules) — **prereg
  stamped and jobs submitted 2026-10-02**, still training. `acs_eval.py` (below) is the harvest
  script, written ahead of data arrival; it has not yet produced real output and is checked in
  only because it's part of the frozen-before-compute record. Results will follow in a later
  commit once E2 is harvested and, if the selected rule beats `cls`, once E4 (new-seed
  confirmation) is done.
