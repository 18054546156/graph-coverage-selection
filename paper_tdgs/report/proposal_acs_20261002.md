## 0. 一页结论

- **论文主线**：覆盖式选样在"标签歧义高"的医学数据上有三处可诊断、可事先预测的失效；对每处失效，从别的领域迁移一个已被证明的修法；
  合起来的方法 ACS 在高歧义区域超过现有 bench（含补进来的低预算 AL 方法），在低歧义区域与 bench 打平——**而且打平的位置也是事先预测的**。
- **novelty 不在新原理，在三件事**：
  1. 诊断：歧义规律（样本外预注册通过）、命题 1/2（跨类信用 → 不纯度 → 损失）、过滤删光可由训练集事先识别（C1/C3）。
  2. 迁移：逐类阈值（Confident Learning / HyperCore）修 F2；预算相变（TypiClust / ProbCover）修 F3；类条件覆盖修 F1。
  3. 证明：每个组件只在它对应失效所在的行起作用（"组件 × 行类型"交互，预先写下哪些行该涨、哪些行该不变）。
- **选参不靠 test，也不靠 val**：retina / breast 的 val 只有 120 / 78 张，val 选参在这里没有意义（09-30 val 门控已在主 5 数据集上失败）。
  每行的配置由**只用训练集的量（每类预算 bpc、类一致率 p_c）决定的规则**给出。行与行的参数不同（满足"按行调参"），但规则是全局的，只有 1–2 个自由参数。
  规则在开发种子 42–46 上定，冻结后在新种子上确认。
- **实话**：高歧义 10 行有真实可修的材料，有希望做到"不显著低于行最好 ≥9/10、平均名次第一"。主 5 数据集上歧义低（tissue 除外），
  规律本身预测"没有可修的材料"，只能主张不显著落后。F3 的直接证据只有 2 行（retina 5%、breast 2%），是最薄的一环。

## 2. 迁移：原理、来源、我们的改动

| 失效 | 被迁移的原理 | 来源领域 / 文献 | 原文做法 | 我们为什么要改 | ACS 里的版本 |
|---|---|---|---|---|---|
| F1 | 子模覆盖的信用应只在同一决策区域内流动 | 子模数据选择（Wei et al. 2015 类条件 FL） | 类内 FL | 已是我们的 cls；在全局 kNN 图上做 mask（不同于作者 per-class 重建图，G1 已证明是不同算子） | 主干不变 |
| F2 | 去噪阈值应逐类设定，否则少数类被系统性删除 | 噪声标签学习：Confident Learning（Northcutt+ JAIR 2021）、HyperCore（Moser+ 2025，Youden 阈值）；反例 Brodley & Friedl 1999 全局共识过滤 | 每类用自身置信度分布定阈值 | 我们没有训练好的分类器，用训练集 UNI kNN 同类占比 a_i 代替"自信度"；阈值取**类内分位数**，保证每类至少留 (1−q) | 逐类分位数过滤 q |
| F3 | 预算低时选典型、预算高时选覆盖，存在相变 | 低预算主动学习：TypiClust（Hacohen+ ICML 2022）、ProbCover（Yehuda+ NeurIPS 2022）、Uncertainty Herding（ICLR 2025） | 全局（无标签）按总预算切换 | 我们有标签和类配额，相变应看**每类**预算 bpc，不是总预算；切换写成训练集量的确定函数 | 类内 典型性↔覆盖 权重 τ(bpc) |

和最近竞争者的差别（论文里必须正面写）：
- **HyperCore**：逐类超球 + 自适应阈值丢点后做 coreset。和 F2 的修法同类。差别在于我们（a）先诊断全局过滤会删光哪些类、并在训练集上事先预测（C3），
  （b）阈值放在覆盖目标之前作为可行域约束，（c）加了 F3 的预算相变。如果 HyperCore 有代码，必须作为对照跑。
- **TypiClust / ProbCover**：无标签冷启动方法。我们在每类内部做相变，不是全局。

## 3. 方法定义：ACS

记号：类 c 的训练池 P_c，每类预算 b = bpc，a_i = 点 i 在 UNI k=50 近邻中的同类占比（去掉自身，与 knnf / condorcet 相同）。

1. **F2 逐类过滤**：候选集 P_c(q) = { i ∈ P_c : a_i ≥ Quantile_q( a_j : j ∈ P_c ) }。q=0 时不过滤。|P_c(q)| ≥ (1−q)|P_c| ≥ b 恒成立，所以不会删光、也不需要补回。
2. **F3 类内预算切分**（10-02 实现时定稿，替代原先的"目标加权混合"写法）：每类先用 herding 在 P_c(q) 上选
   k_h = ⌊τ·b + ½⌋ 个典型点，再用 cls 的懒贪心（λ=0.5 混合目标，含全局项）从这些点热启动，选满剩下的 b − k_h 个。
   - 这样两端都是精确的已知方法：τ=0 就是 cls，τ=1 就是 herding，不需要在两个目标之间人为定归一化比例；
   - herding 用作者的 `_select_herding`，与 bench Herding 同一实现；
   - 过滤只限制"谁能被选"，不改覆盖的需求（与 MVF 相同）。
3. **F1**：跨类信用 mask 不变（主干）。
4. **选参规则**（不读 val / test）：
   - τ(b) = 1 若 b ≤ b*，0.5 若 b* < b < 2b*，0 若 b ≥ 2b*（阶梯形，取值都落在 E2 网格里，确认阶段不出现没筛过的 τ）。自由参数只有 b* ∈ {5, 10, 20}。
   - q 是一个全局常数 q* ∈ {0, .25, .5}。
   - 这样每行的 (q, τ) 不同，但只由 bpc 决定。b* 和 q* 在开发种子上定（§5 E2），冻结后确认。

**恒等检查（实现正确性的硬门）**：
- q=0, τ=0 ⇒ 选择集与已 staging 的 cls 逐位相同（全部 10 行）；
- q=0, τ=1 ⇒ 与 bench Herding 逐位相同（若 Typ_c 的归一或 tie-break 导致不同，报告差异，不放行）；
- q>0 ⇒ 每类保留 ≥ (1−q)|P_c|，被删类数 = 0。

**重要的边界说明**：bpc ≤ 5 时 ACS ≈ 逐类过滤 + herding。在这些行上方法本身没有新东西，新东西是"什么时候该切过去"的规则。论文要这样写，不要把 retina/breast 上的胜利算成新算子的胜利。

主终点：BA；第二终点：最差类召回。配对按训练种子，单侧配对 t 检验，行内对多个对照用 Holm 校正。

| 门 | 条件 | 主张 |

| **G1 高歧义 BA** | ACS 不显著低于行最好方法（含新基线）≥ 9/10 行，且平均名次第一 | "高歧义区域 ACS 是最强或统计上打平" |
| **G2 高歧义双轴** | 没有任何对照在 BA 和最差类召回上同时显著支配 ACS ≥ 9/10 行 | 尾部也不输 |

| **G4 主行** | 不显著低于行最好 ≥ 8/10；H-main 成立 | 低歧义区域打平，且与规律预测一致 |

- G1 或 G2 只到 7–8/10：如实报，叙事变成"诊断 + 规律 + 一个在高歧义区域占优的迁移方法"，仍可写。
