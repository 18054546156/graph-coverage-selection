## 0. Why this route (from the medical data, not from the method)

Graph-A2, TDGS and every baseline in this benchmark select samples in the embedding space of **one** frozen encoder, UNI.
UNI was pretrained on H&E histopathology. Of the 5 datasets:

| Dataset | Modality | Match to UNI |
|---|---|---|
| path | H&E | matches |
| blood | blood-smear light microscopy | does not match |
| tissue | kidney-cortex DAPI fluorescence, grayscale | does not match |
| organA / organS | abdominal CT slices, grayscale | does not match |

Evidence already on record:

- **Graph-A2 names this as its main limitation:** "On TissueMNIST, where UNI embeddings poorly separate fluorescence microscopy classes, all selection methods converge." TissueMNIST 2% is also the only condition where Graph-A2 did not win.
- **MedCAL-Bench (arXiv 2508.03441)** found that encoder choice affects cold-start selection, that medical-specific encoders are not necessarily better than general ones, and that no single strategy is optimal.
- **In our own data,** every contrast in Round 2 that is significantly different from 0 comes from tissue, the dataset with the greatest mismatch. Excluding tissue, `tdgs_cls − graph_a2` = +0.71 and `tdgs_cls − a2_perclass` = +0.03.

Practical problem: when building a new medical dataset there is no test set, and you cannot know in advance which encoder's geometry "is right" for this modality.
Hypothesis H_enc: selection quality depends on the encoder, and no single encoder is best on every dataset.
The response is to make the selection objective robust across encoders, rather than to pick one encoder in advance.

## 1. Model

Views v ∈ V = {UNI, DINOv2-L/14 (LVD-142M), CLIP ViT-L/14 (OpenAI)}. All are frozen, 224 input, CLS token, L2-normalized.

- UNI train embeddings **reuse the archived cache directly**.
- Preprocessing was checked by a 512-sample smoke test on blood and organA: the re-extracted UNI is **bit-identical to the archive** (max|Δ| = 0, job 35202).

Each view gets its own TDGS objective, identical to Round 2 and normalized to [0, 1]:

```
K^v   = A^v_sym + (A^v_sym)^2,   A^v = author kNN (k=50, global)
F_v(S) = (1-λ)·F_G^v(S)/F_G^v(P) + λ·F_task^v(S)/F_task^v(P),  λ = 0.5 (fixed; not tuned)
F_G^v(S)    = Σ_i max_{j∈S} K^v_ij
F_task^v(S) = Σ_i w_i max_{j∈S} 1[y_i=y_j] K̄^v_ij,  w_i = 1/(C·n_{y_i})
Constraint: |S ∩ P_c| = bpc = ⌊N·ratio⌋ // C (author's formula)
```

Primary arm **mv_rob** approximates `max_S min_v F_v(S)`. The surrogate is SATURATE-style (Krause et al. 2008):

- For each level c ∈ {0.80, 0.85, 0.90, 0.93, 0.96, 0.98, 1.0}, lazy-greedy maximize `Σ_v min(F_v(S), c)`, which is monotone submodular for every c, under the per-class quota.
- Among the 7 candidates, keep the S with the largest `min_v F_v(S)`.
- This choice uses **only train-pool quantities**, with no val, no test and no training.
- **No approximation guarantee is claimed.** SATURATE's guarantee requires relaxing the budget; here the quota is exact.

Other arms:

| Arm | Definition | Role |
|---|---|---|
| `mv_mean` | `(1/|V|) Σ_v F_v` | Plain average (monotone submodular, partition matroid ⇒ greedy ≥ 1/2). If it is as good as mv_rob, report the simpler one |
| `cls_cat` | Single graph on concatenated embeddings `[z_uni, z_dino, z_clip]/√3` + TDGS | Naive feature fusion |
| `cls_dinov2`, `cls_clip` | TDGS on a single view | With the existing `tdgs_cls` (= cls_uni), the single-view reference set |
| `a2_dinov2`, `a2_clip` | Graph-A2 (λ=0) on a single view | Encoder sensitivity of the baseline itself |
| **`hpc_cls`** (R2) | Global F_G (UNI) + task branch on the author's **per-class rebuilt** graph (block-diagonal K_pc) with class-flat weights, λ=0.5 | Differs from `tdgs_cls` **only** in which graph the task branch uses. The matched control that isolates "task credit on the global graph" |

Self-checks, built into `mv_select.py` (abort on failure):

- On the single UNI view, the generic multi-term greedy reproduces the selection order of `greedy_blended` exactly for both graph_a2 and tdgs_cls. The local synthetic unit test passes: λ ∈ {0, 0.5, 1} all identical, and cap=∞ equals the plain sum.
- Every arm fills its quota exactly.

## 2. Precise differences from existing work (verified against primary sources, except where noted)

| Work | What it does | Difference from R1 |
|---|---|---|
| Graph-A2 (arXiv 2606.22002) | Single encoder, UNI, global kNN, A+A², FL, per-class quota | We handle encoder uncertainty with multiple views and a robust aggregate, plus class-scoped credit |
| Wei, Iyer & Bilmes ICML 2015 eq. 6 | Class-conditional FL, single feature space | Same as the per-view task term. We add no novelty to this term itself |
| Krause et al. 2008 SATURATE; Anari et al. 2019 | Theory and algorithms for robust submodular maximization | We adopt the algorithm; its application to encoder uncertainty in medical coreset selection is the new part (**not cited from full text; to be verified**) |
| Xu 2026, Fair Multi-View Determinantal Coresets (arXiv 2608.18181) | Max-min across views, DPP log-det, Stiefel relaxation; synthetic data only, no real-data results | Their objective is diversity via log-det; ours is coverage via FL on a graph kernel, with a class quota and a medical-imaging benchmark. Their argument that averaging a kernel hides a failing view is exactly what mv_rob vs mv_mean tests |
| MedCAL-Bench (arXiv 2508.03441) | Benchmarks 14 FMs × 7 CSAL strategies **one at a time** | They show encoder dependence; they do not aggregate across encoders |
| ε-AS (arXiv 2608.03249) | Adapts the typicality–coverage balance via OT; single representation | An orthogonal adaptation axis |

The novelty search is **not exhaustive**. I searched with WebSearch using 4 query groups and found no paper that does "multi-encoder robust facility location for medical data selection". That does not prove none exists.

## 3. Hypotheses and endpoints

**Primary metric:**

- Test balanced accuracy (BA).
- Paired by training seed; dataset mean (each dataset gets equal weight).
- 95% hierarchical bootstrap CI (B = 20000), resampling datasets and then seeds within dataset.
- Also reported: excluding tissue, number of datasets with the same sign, and worst-class recall (secondary; never promoted to primary).

**No test-set tuning:**

- λ = 0.5, k = 50 and the c grid are fixed in advance.
- The view weights are equal, and mv_rob's c is chosen by train-pool F_v.
- The only thing allowed to use val is the reference arm **val-selected single view**: per dataset, argmax_v of the train→val kNN BA (k=50 cosine weighted vote). This is computed and logged by `mv_select.py`.
- The "oracle best single view" uses test and serves **only** as the yardstick for regret. It is never used to make a choice.

**Zero-training diagnostic D1** (logged in `r3/report/*_r3.json`), per view:

- cross-class edge share of K
- train kNN-LOO BA
- train→val kNN BA
- cross-view coverage matrix F_v(S_arm)
- Jaccard

## 4. Gates (fixed before results)

### S0: selection space (0 GPU; before P4-b/c/d are trained)

- **S0-a, non-redundancy:** J(cls_uni, cls_dinov2) and J(cls_uni, cls_clip) are both < 0.5 on ≥3/5 datasets.
  Otherwise the views are selection-equivalent, the multi-view route has no power, and **P4-b/c/d are not trained. STOP R1.**
- **S0-b, encoder heterogeneity** (does H_enc hold at zero cost): the val kNN BA ranking of the three views is not the same on all 5 datasets.
  If one view beats the other two by ≥2pp of val kNN BA on all 5 datasets, record that H_enc is **not supported**. Training proceeds, but mv_rob's primary comparator becomes that view's `cls_<v>`.

P4-a (hpc_cls) is trained unconditionally; it does not depend on S0.

### G-R2: matched hybrid per-class (hpc_cls, 2%, n=5)

- `tdgs_cls − hpc_cls` ≥ +0.5pp, and ≥4/5 datasets with the same sign ⇒ "task credit on the global graph" is an **independent component**, and TDGS's difference from Wei eq. 6 + per-class graph survives.
- Otherwise ⇒ TDGS is reported as "Graph-A2 global term + class-conditional FL (Wei 2015)", and **must not** be written as a new criterion. The same applies if excluding tissue is ≤ +0.3.

### G-MV stage 1 (2%, seeds 42–44, n=3, screen)

Primary contrast Δ = BA(mv_rob) − BA(tdgs_cls):

- **GO** (continue to n=5, 5%, and independent validation) requires all of:
  - Δ dataset mean ≥ +0.5pp
  - ≥3/5 datasets positive
  - Δ excluding tissue ≥ +0.3pp
  - mv_rob − val-selected single view ≥ 0 (dataset mean)
- **STOP** R1: Δ dataset mean ≤ 0. The multi-view route closes. The paper keeps "encoder sensitivity" as a diagnostic finding only, and training on this line stops.
- **PIVOT** (anything in between):
  - If val-selected single view − tdgs_cls ≥ +0.5 and mv_rob does not beat it, switch to the simpler "choose the encoder by val kNN" (the "multi-view" claim is dropped).
  - If mv_mean − mv_rob ≥ +0.3, the "robust" claim is dropped and the averaged version is reported.
  - If cls_cat ≥ mv_rob, report feature concatenation.
- Power, stated honestly: the n=3 per-dataset MDE is several pp. Stage 1 is a **screen**, and a GO is only a license for the n=5 confirmation, not a conclusion.

### G-MV stage 2 (only if stage 1 is GO)

- 2% extended to n=5 (seeds 45/46).
- 5% at n=5 for mv_rob, the best single view, and tdgs_cls. Staging needs `RATIO=0.05`.
- Success at 5%: dataset mean ≥ 0 and not significantly worse than tdgs_cls. Given G4, 5% is not required to show a gain.
- Secondary: regret_d(arm) = BA(oracle-best single-view cls arm) − BA(arm). Report mean and max regret; a robust method should have the **smallest max regret**.

## 6. Failed routes explicitly not repeated

Difficulty or direction demand (−2.51 / −0.20), quota reallocation, Voronoi, stability gating, kernel variants on the same UNI view (the "kernel variants" exclusion in HANDOFF §11), and new metrics.

R1 does change the kernel, but the variable is **which representation**, not the propagation or weighting of the same representation. That keeps it clear of the closed line "graph-side innovation is exhausted", which was about the same UNI geometry.
If S0-a fails (the views are selection-equivalent), this distinction does not hold either, and R1 stops.
